# dsh-marginalia

在「对话」里选中助手回复的一段文字，光标右上方会出现复制、标红、划线或提问，右键也同样。这些句子收进旁边的「学习」页。

## 怎么用

插件已经挂在桌面版 profile `desktop` 上。完全退出 DeepSeek Harness 再打开（窗口关掉后如果还留在托盘里，也要退出）。

留在「对话」。用鼠标选中气泡里助手反馈给你的那段文字，复制、标红、划线和提问会出现在光标右上方，右键也能打开同一张卡片。同一段再次选中时，按钮会变成「取消标红」或「取消划线」。自己发出的消息和思考过程不会进这个菜单。笔记在「学习」页，可以写批注、删除、复制。

选「提问」，或在笔记上点「提问」，输入例如「这段是什么」。提问和追问都可以另选模型。打开的子进程里，输入框上方也能换模型，下一条回复就改用它。这句话会先划线，并在旁边的侧栏打开这条进程。侧栏里可以像主对话那样接着写，新的一轮往下排在这一页。主对话上对同一条再追问，消息也发到这条进程，不会另开一层。已经开过的进程上划线追问，同样往下续，不再变成「主进程 → 子进程 → 子进程」。进程记得自己前面的回答，也和主对话并排，互不取代。回答不写进主对话下面。句末的引用符号展开仍是便利贴，里面是最新一条回复。

更早开过的一次性进程不能往下续。回到主对话重新提问，新的就可以接着写。

## 笔记放在哪

`%USERPROFILE%\.dsh\study-notes\` 下面，每个工作区一个目录。不写进项目仓库。

## 这一步的边界

- 一次标注最多 4000 字，一条对话最多 400 条。
- 同一段再次选中可以取消标红或划线。另一段相同的文字如果也被选中，会一起取消。
- 新开的提问可以选择子进程的模型。已经打开的子进程也可以换，下一条回复用新的。
- 还没有模型整理，也没有 PDF。
